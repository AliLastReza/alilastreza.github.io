# سایت چندصفحه‌ای استخر دانشگاه قم

## ساختار
- `index.html` صفحه اصلی
- `about.html` معرفی مجموعه
- `schedule.html` سانس‌ها و قوانین
- `tickets.html` بلیت و تخفیف
- `contact.html` تماس و آدرس
- `styles.css` تمام استایل‌ها
- `script.js` منوی موبایل، انیمیشن ورود و active nav

## اجرا
فایل `index.html` را مستقیم در مرورگر باز کنید.

این قالب بدون فریم‌ورک و با HTML/CSS/JS خام ساخته شده است.

فونت پیش‌فرض تمام صفحات: **Vazirmatn** از Google Fonts است؛ برای نمایش فونت در حالت آنلاین، اتصال اینترنت لازم است.
